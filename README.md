# HashMap

A simple HashMap implementation built from scratch in JavaScript as part of my Data Structures and Algorithms learning.

## Features

* `set(key, value)`
* `get(key)`
* `has(key)`
* `remove(key)`
* `length()`
* `clear()`
* `keys()`
* `values()`
* `entries()`

It uses **Linked Lists** to handle collisions and a **load factor of 0.75** with an initial capacity of `16`.

This implementation is a bit sloppy right now 😅, but I'm learning from it and will improve and refactor it in the future.

## Tech

* JavaScript
* Node.js
* Linked Lists
